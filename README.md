# Portfolio Hamdani Nur Arifin

Single static page (`index.html`), plain HTML + CSS, no build step. Fonts (Inter, Space Grotesk) load from Google Fonts. Dark/light follows `prefers-color-scheme`.

Preview: open `index.html` in a browser, or run `python3 -m http.server` in this folder.

Deploy: upload the folder to any static host (Cloudflare Pages, GitHub Pages, Netlify). Not published yet.
